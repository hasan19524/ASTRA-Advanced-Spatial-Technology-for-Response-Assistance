## The rule that makes this phase attach cleanly

**Presentational components fetch nothing.** They take data + callbacks. Pages own fetching via
stores. If you follow this, Hasan's endpoints land under your components without a single
conversation — a missing field becomes a TypeScript error, not a demo-day surprise.

Shared envelope, used by **every** store — no exceptions:

```ts
interface ApiError { status: number; detail: string }   // never a raw string
interface Async<T> { data: T | null; loading: boolean; error: ApiError | null }
type WsState = "idle" | "connecting" | "connected" | "reconnecting" | "offline"
```

`wsState` is the **only** source for any "live" label. A dead socket renders "offline".

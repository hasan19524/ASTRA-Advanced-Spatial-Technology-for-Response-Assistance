## 📜 The contract (Hasan implements exactly this — consume it, don't guess)

| Endpoint | Shape |
|---|---|
| `POST /api/v1/incidents` | multipart: `title*`, `description*`, `category*` (8 enums), `region`, `latitude`, `longitude`, `location_text`, `photo` (optional file) → 201 `{...IncidentOut, grouped: bool}` |
| `GET /api/v1/incidents` | `category, assessment, verification, region, limit, offset` → `{items, total, limit, offset}` |
| `GET /api/v1/incidents/{id}` | `IncidentOut` + `reports[]` + `assessments[]` (timeline) |

- **IncidentOut:** `id, title, description, category, region, latitude, longitude,
  location_text, sensitivity, assessment_status, visibility, verification, response_phase,
  lifecycle, report_count, created_at, updated_at`.
- **RESTRICTED/HIDDEN rows:** only admin/officer receive them — for you they're simply **404**:
  render your not-found state, never an error page.
- **WebSocket** `ws://localhost:8000/ws/map?token=<access_token>` (AD-10 — token on handshake,
  invalid → closed 4401, reconnect with a fresh token):
  - connect → `{"channel":"incidents:map","type":"connected"}`
  - new public incident → `{"channel":"incidents:map","type":"incident.created","data":<IncidentOut>}`

Evidence: [`plan-phases.md` §7.2](../../plan-phases.md). Both endpoints are proven against the
live API, so this is integration, not research.

- [ ] `POST /api/v1/voice/stt` — multipart proxy to `https://api.vachana.ai/stt/v3`
  - **`language_code` is required** (422 without it) — accept it from the client, BCP-47 passthrough (AD-16)
  - accept audio ≤ 60 s, WAV/MP3/OGG/FLAC/AAC/M4A

  - return `SttOut { transcript, language, model, latency_ms }`
- [ ] `POST /api/v1/voice/tts` — JSON proxy to `https://api.vachana.ai/api/v1/tts/inference`

    `400 JSON decode error` during the spike. Encode explicitly; do not trust default encoding.

      (AD-16: no hardcoding; the backend passes codes through untouched).

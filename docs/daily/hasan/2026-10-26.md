- **Two real bugs found and fixed by the verification** (this is why we prove, not assume):
  1. `argon2-cffi==23.1.0` calls `PasswordHasher.verify(hash, password)` — **hash
     first**. Our wrapper passed the password first, so every correct login returned
     401 while register (which never verifies) looked fine. Fixed in
     `api/app/core/security.py`, version pinned in `requirements.txt`, comment on the
     line so it never silently regresses.
  2. `scripts\verify-auth.ps1` sent JSON bodies as command-line arguments —
     PowerShell 5.1 mangles embedded quotes, so the API received garbage JSON (422s).
     Bodies now go through a temp file with `curl -d @file`.

## Decisions made today

- **RESTRICTED keeps the visibility axis pure** — a restricted incident stores
  `visibility=PUBLIC_UNVERIFIED`; the public map query is
  `visibility = 'PUBLIC_UNVERIFIED' AND sensitivity = 'PUBLIC'`, so restriction is enforced at
  query time, never by overwriting another axis. Written into `docs/architecture.md`
  (sensitivity rule, Day 2 implementation note).
- **AD-3 taken literally:** sim table = `sim_runs` (the day plan's `simulation_runs` was
  prose — AD-3 says `sim_*`).
- **`task.view` added to the permission matrix** — an allowed visible extension ("extend as
  features land, never silently"); listed here so nobody discovers it by accident.

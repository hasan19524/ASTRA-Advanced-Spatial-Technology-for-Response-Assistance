## Decisions made today
- **Type unification** — migrated `useIncidents` store + incidents list/detail/map pages from `MockIncident` to the real API schema types (`IncidentOut` / `IncidentDetailOut` / `IncidentPageOut` / `ReportOut` / `AssessmentOut` in `web/src/api/types.ts`). The backend `Incident` has no `severity`/`location`/`lat`/`lng`/`poll`, so list columns now read `location_text` / `assessment_status` / `verification` / `response_phase` and `latitude`/`longitude`. Detail renders `reports[]` evidence (photo URLs via `${API_URL}${media_path}`) and `assessments[]` timeline. Mock layer kept as fallback when the API is down/404/501.
- **WS auto-reconnect** — `connectWS(token)` opens one shared `/ws/map?token=<jwt>` socket on the incidents store; `incident.created` envelopes prepend to the list (serves both `/incidents` and `/map`). Reconnects when the token changes (silent-refresh case). WS is a live enhancement: failures never fail a page.
- **Photo** — client-side type (jpeg/png/webp) + 5 MB check before upload, preview thumbnail, `URL.createObjectURL`; sensitivity shown as read-only "PUBLIC by default" for citizens (endpoint doesn't accept it; authorized override comes later).
- **Geolocation** — "Use my location" → `navigator.geolocation`; declined/unavailable → NCR center (28.61, 77.21) default, with a line showing exactly what will be sent.
